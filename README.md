## Featured projects

### [汉字大全 — Compêndio de Hanzi](https://github.com/gabedossa/dicionario_chines_br)

Brazilian Portuguese visual dictionary for Chinese characters, built with Next.js, React and TypeScript. It supports search by hanzi, pinyin or meaning, HSK and tone filters, paginated results, detailed character views and graded reading texts.

### [ArtisanVault](https://github.com/gabedossa/ArtisanVault)

Full-stack marketplace project connecting artists and clients. It combines a Spring Boot and PostgreSQL API with a Next.js and TypeScript front end, including artist profiles, portfolios, services, orders and role-specific dashboards.

> Academic project under active improvement. Authentication and authorization are not yet production-ready.

### [DevJobs UI](https://github.com/gabedossa/devjobs_ui)

Remote developer job board built with Next.js and TypeScript. It consumes and normalizes data from the Remotive API, with search, country and employment filters, incremental pagination, responsive layout and persistent dark mode.
